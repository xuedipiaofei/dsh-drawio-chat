# dsh-drawio-inline (work in progress)

A DeepSeek Harness plugin that renders draw.io diagrams inline in the chat: the model composes a diagram, a zoomable local viewer appears in the transcript — no draw.io account, no npx server, no external service.

This repository is the scaffold (bundle contract + health route + locale dictionaries); the tool and viewer land in follow-up commits. Research notes live under `notes/drawio/` in the workspace.

Apache-2.0; build-preset and third-party attribution in [NOTICE.md](NOTICE.md).
